Copy this to `intake.md` to run the pipeline for evaluation, for tuning a skill, for a demo, or
for onboarding someone to the method.

⛔ **A run started from this file records itself as synthetic in `strategy/frame.md`**, in the
same place and the same way a run with no critic pass records that. Nothing produced by a
synthetic run may be presented as an engagement output.

⭐ **Why this file exists.** Every guard in this command assumes a live sponsor — the verbatim
mandate, the proposition the agent may not write, the gates phrased as sponsor questions. Without
a sanctioned fixture the only way to exercise the tool is to defeat its guards, which teaches
exactly the habit the guards exist to prevent.
